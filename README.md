# NES Tetris Clone

A recreation of Nintendo's NES Tetris with some extra features written in C++ using SDL3.

Heavily work in progress, and only updated when I have bursts of motivation to work on the project

## Features
# Game modes:
- Standard
- Standard + QOL options (Grid, Hard drop, Ghost Piece, 7-bag, holds)
- Clear Garbage (Similar to Type B in the original game)
- Burn Marathon (creates new lines of garbage based on a timer)

# Extra options:
- Show Grid
- Hard Drop
- Show Ghost
- Enable 7-bag
- Enable Hold
- Random Rotations

# Other stuff:
- Highscores based on mode/option combinations
